# Flutter Firebase Starter

A minimal Flutter app wired up to Firebase (Core and Cloud Firestore). It's a single `main.dart`, used to practise the Firebase setup.

## Tech stack

Flutter · Dart · Firebase Core · Cloud Firestore

## Getting started

```bash
flutter pub get
flutter run
```
